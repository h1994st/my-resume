The template

One class file owns the layout; a resume file holds only content. These are the real pages, built by CI from this commit: Duna's complete canonical resume, and the one-page variant tailored for a job.

What to notice, from the top of a page down:

  1. Section tabs

    Each section opens with a graphite tab and a rule to the margin. Sections always print in the same order (Summary, Experience, Projects, Education, Publications, Service, Honors & Awards), whatever the order in the source; leave one out to drop it.

  2. A timeline spine

    Roles and projects hang off one line, a ring for each entry, and the line keeps going across a page break.

  3. Date pills

    Dates are written once as 2023-04 or present; the class prints them as Apr 2023 – Present.

  4. Facts cited by key

    A role's title, employer, place, and dates are defined once in common/facts/ and cited by key, so every variant prints them the same way. 

    % common/facts/roles.tex
\defrole{windowsill}{
  title = {Head of Windowsill Operations},
  org = {Sunbeam Estates},
  location = {Living Room},
  start = 2023-04, end = present,
}
    % canonical/resume.tex
\begin{role}{windowsill}
  \item Initiated and led
    ``Operation Red Dot'', …
\end{role}

  5. A typo fails the build

    Cite windowsil instead of windowsill and the build stops with an error that names it. So do a missing field, a duplicate section, and a date like 2024-13. 

    ./canonical/resume.tex:60: Package resume Error: Unknown role key 'windowsil'.

  6. No stranded titles

    Pages break between bullets, never between a role's title and its first bullet or between a heading and its first entry. A test moves the content through 51 page positions to check.

Get started

Use the repo as a template and clone your copy. Then, on macOS with Homebrew: 

brew bundle          # BasicTeX, just, tex-fmt, prettier, poppler
just deps            # + the extra TeX Live packages (asks for sudo once)
just build           # canonical/resume.tex → canonical/resume.pdf
just check applications/2026-09-granary-senior-mouser   # build + check it fits in 2 pages
just test            # run the template tests

To make it yours, put your details in common/profile.tex and common/facts/ (or run /update-resume in Claude Code and let it ask for them), and rewrite canonical/resume.tex. For a job, run /customize-resume with the posting.

  • The repository on GitHub the source and the full README
  • CLAUDE.md the rules Claude follows, starting with: never invent or inflate a claim
  • The customize-resume skill tailors a variant to a job posting, and stops for your approval
  • The update-resume skill adds new experience to the facts and the canonical resume
